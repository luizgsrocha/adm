# Padrão de índice interno

As páginas extensas do portal devem oferecer navegação por âncoras para facilitar a revisão sem dividir o conteúdo em vários arquivos.

## Padrão

- índice horizontal e rolável no celular;
- links para seções da própria página;
- rolagem suave;
- `scroll-margin-top` para compensar cabeçalhos fixos;
- nomes curtos orientados ao assunto de estudo.

## Situação atual

- `rae.html`: índice por Recebimento, Descarga, Responsabilidade, Passagem de função, Prazos e Pontos fortes.
- `rde.html`: já possui índice lateral no desktop e navegação horizontal no celular.
- `sindicancia.html`: já possui navegação por capítulos no desktop e abas no celular.

O mesmo padrão pode ser aplicado progressivamente às demais páginas extensas.
