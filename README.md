# Operações Ofensivas — Mapa Interativo

Mapa mental interativo desenvolvido para auxiliar o estudo de Operações Ofensivas.

## Recursos

- Organização visual dos assuntos em bolinhas interativas;
- Movimentação automática com efeito de repelência;
- Exibição de informações ao selecionar cada assunto;
- Imagens de apoio ao estudo;
- Ampliação das imagens por meio de pop-up;
- Interface adaptada para computadores, tablets e celulares.

## Acesso

[🌐 Abrir o mapa interativo](https://luizgsrocha.github.io/adm/)

## Utilização

Clique nas bolinhas para visualizar os respectivos conteúdos. As bolinhas podem ser movimentadas livremente pelo mapa. Clique nas imagens para abri-las em tamanho ampliado.

## Finalidade

Material elaborado exclusivamente para estudo e revisão.
